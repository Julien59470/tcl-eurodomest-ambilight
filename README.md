# Eurodomest Ambilight TCL Android TV

Application Android TV expérimentale pour TCL Google TV, Universal Ambient Light (UDP Raw, 19446) et boîtier Eurodomest/Tuya.

⚠️ Cette application n'a pas encore été validée sur la TCL 55Q6C ou sur le contrôleur Eurodomest 6208000100. Les fonctions DRM restent limitées par Android.

Le fichier APK de développement est dans la racine du dépôt. Ne saisissez jamais votre Local Key Tuya sur un site tiers.
